Encrypted Storage — the PIN Gate

Two independent layers, not one. Raw file theft alone fails. Device compromise alone fails. Only both together succeed.

K_user = HKDF(K_device, user_id) — the architecture's literal formula — has no PIN in it. Taken alone, anyone who can read K_device (itself only OS-encrypted) could derive the same K_user without ever entering a PIN. Resolved by giving the PIN a real, separate job: it wraps the enrollment token itself, as a row inside the K_user-encrypted partition — so recovering the real secret needs both the device's own key material and the correct PIN.

Verified live, end to end, on a real Samsung Galaxy A06 with two independently-enrolled Cognito profiles and two different PINs — not just two profiles that each independently worked, but one profile's PIN actually tried against the other's data and watched fail.
