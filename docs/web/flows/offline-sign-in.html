Offline Sign-In — the Core Hard Part

Every lifeline below runs entirely on-device. No lifeline in this diagram is capable of making a network call.

Start: a person taps their name and enters their PIN. End: a specific, named PASS or FAIL shown on screen. OfflineVerifier checks signature, expiry, device-id, and epoch — then proves the person unlocking the token actually holds the matching private key via a fresh challenge-response, not just a copied token blob.
