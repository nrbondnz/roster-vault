Airplane Mode Setup and Usage

The literal real-world procedure that makes this whole project's core claim real rather than theoretical — and exactly what was run against a real Samsung Galaxy A06 this session, airplane mode genuinely on.

Every other flow on this site proves a mechanism works in isolation. This one proves the mechanism works with the network physically gone — the one claim this entire project exists to make good on. Two paths reach the same place: a real end user flipping a switch in Settings, and the exact adb commands used to verify it this session. Both converge on the same code path — OfflineVerifier has no http or Amplify import anywhere in it, so there is no network call left to make regardless of which path got you here.
