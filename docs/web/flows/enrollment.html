Enrollment — the One Online Step

Everything later that works offline is provisioned here, once, while the device genuinely has a network connection.

Start: a real person taps "Add a person" on RosterScreen and signs in with real Cognito SRP. Device and per-user ECDSA P-256 keypairs are generated (or already exist — both services check before creating, never blind-generate). Both public keys and the ID token go to the enroll mutation. The Lambda preserves any existing epoch, signs a token via KMS, writes DeviceEnrollments, and returns it. End: the token is verified locally against the issuer public key baked into the app — proving the whole round trip actually worked, not just that a response came back.
