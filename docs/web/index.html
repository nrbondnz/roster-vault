Operational notes

Trust anchors

  • Issuer key (KMS) — proves a token came from the real identity service; private key never leaves KMS.
  • Device keypair — ties every token to this physical device.
  • Per-user credential — bound to one person, on one device, gated by their own PIN.

Real storage, verified not assumed

  • sqlite3 3.x's sqlite3mc cipher build — self-contained, no OpenSSL dependency (unlike the now-EOL sqlcipher_flutter_libs).
  • Verified with raw-bytes ciphertext checks on both Windows and the real Android deployment target.

What's proven, not just built

  • Offline sign-in demonstrated with the device's network genuinely disabled, confirmed via the status bar and adb, not just code review.
  • Cross-profile isolation demonstrated by actually trying one profile's PIN against another's data.
