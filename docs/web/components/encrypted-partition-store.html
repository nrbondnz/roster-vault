"Real Partitioning, Not Just a UI Filter" — one genuinely encrypted SQLite file per enrolled person, keyed by their own K_user.

Cipher build
sqlite3mc — SQLite3 Multiple Ciphers

sqlcipher_flutter_libs — the obvious first choice — turned out to be EOL upstream (its own pub.dev listing says outright: "Not used anymore, update to version 3.x of package:sqlite3 instead"). package:sqlite3 3.x bundles cipher support natively via Dart's native-asset build hooks, with three selectable binary variants. sqlcipher itself still links OpenSSL on Windows, Linux, and Android — the exact dependency this project doesn't have installed — sqlite3mc is self-contained, downloaded as a precompiled binary per platform. Selected via pubspec.yaml's hooks.user_defines.sqlite3.source.

Verified with real ciphertext, not assumed: a written file's raw bytes are neither the plaintext "SQLite format 3" header nor do they contain the plaintext value anywhere; a wrong key fails to read existing data (SqliteException(26): file is not a database); the right key still works. Checked on Windows first, then confirmed with a live on-device test on the real Android deployment target — the same "Test encrypted storage" button still lives in the debug screen reached via "Add a person."
