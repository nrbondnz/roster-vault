Cognito User Pool

Confirms who someone actually is, once, online — the one moment this app behaves like any other app.

Auth flows
ALLOW_USER_SRP_AUTH (client), ALLOW_ADMIN_USER_PASSWORD_AUTH (CLI verification only)

LoginScreen calls Amplify.Auth.signIn — plain email/password SRP, nothing offline-specific happens here. explicitAuthFlows also allows ALLOW_ADMIN_USER_PASSWORD_AUTH, deliberately scoped to callers who already hold this project's own AWS IAM credentials (not the broader ALLOW_USER_PASSWORD_AUTH, which would expose direct password auth to any client holding the app's client id) — added so the enrollment Lambda could be verified directly from the CLI before any Flutter login screen existed.

Once signed in, the ID token from Amplify.Auth.fetchAuthSession() is sent as the Authorization header on the enroll mutation — AppSync verifies it before the resolver ever runs; the Lambda reads the already-verified identity from $ctx.identity.
